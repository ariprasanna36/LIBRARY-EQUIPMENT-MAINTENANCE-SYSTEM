# LIBRARY-EQUIPMENT-MAINTENANCE-SYSTEM
The Library Equipment Maintenance System is a simple and efficient system designed to help libraries manage, monitor, and maintain their equipment in an organized way.  The system keeps track of equipment details, maintenance schedules, equipment conditions, repair activities, and maintenance history.
